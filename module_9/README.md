# Мини-проекты 2-го года обучения DS/ML (Skillfactory)

Практические проекты из дополнительных модулей курса.

## Проекты

### [ab_testing.ipynb](ab_testing.ipynb) — A/A/B-тестирование маркетплейса

Анализ результатов A/A/B-эксперимента: проверка корректности сплит-системы (A/A-тест) и оценка эффекта нового алгоритма рекомендаций (A/B-тест). Статистические тесты (Шапиро-Уилк, t-тест, Манна-Уитни) для метрик CTR, GMV, количества покупок.

**Результат:** A/A-тест провален — контрольные группы статистически значимо различаются. A/B-тест некорректен из-за нарушенной методологии.

---

### [anomaly_detection.ipynb](anomaly_detection.ipynb) — Детектирование аномалий

Поиск аномалий в данных о продажах трёх брендов методами Z-score, IQR, Isolation Forest и DBSCAN. Сравнение подходов и визуализация результатов.

**Результат:** DBSCAN выявил 9 аномальных дней. Isolation Forest показал высокую чувствительность. Комбинация методов даёт наиболее устойчивый результат.

---

### [bayesian_methods.ipynb](bayesian_methods.ipynb) — Байесовские методы в ML

Построение байесовской линейной регрессии с помощью PyMC3 и сравнение с классической регрессией. Анализ апостериорных распределений коэффициентов и оценка неопределённости.

**Результат:** Коэффициенты байесовской и классической регрессий согласуются. Байесовский подход дополнительно предоставляет доверительные интервалы для каждого коэффициента.

---

### [uplift_modeling.ipynb](uplift_modeling.ipynb) — Uplift-моделирование

Подбор оптимального алгоритма для оценки uplift-эффекта на данных Criteo. Сравнение S-learner, T-learner, TwoModels и UpliftRandomForest (CausalML) по qini-score.

**Результат:** S-learner показал лучший qini-score на тестовой выборке (2169.5) при низком переобучении.

---

### [wine_quality_monitoring.ipynb](wine_quality_monitoring.ipynb) — Классификация качества вина с мониторингом

Бинарная классификация качества красного вина (LightGBM) с мониторингом метрик модели через Prometheus и Grafana. Реализовано потоковое дообучение на новых данных.

**Результат:** F1-score = 0.60, Recall = 0.77. Настроен пайплайн сбора метрик (model_f1_score, model_precision, model_recall) и их визуализация в Grafana.
