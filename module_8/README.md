# Проект: Прогнозирование Объемов Продаж для Сети Магазинов Favorita

## 1. Описание проекта

Этот проект посвящен анализу и прогнозированию объемов продаж тысяч товаров, реализованных в различных магазинах сети Favorita, расположенных в Эквадоре. Основная цель — разработать инструмент для прогнозирования будущих продаж, что позволит оптимизировать запасы, улучшить логистику и повысить операционную эффективность. Проект включает в себя глубокий анализ временных рядов, разработку признаков, а также применение различных моделей машинного обучения для достижения наилучших результатов прогнозирования.


## 2. Цели проекта

Основные цели проекта включают:
* Выполнение сезонной декомпозиции временного ряда и теста Дикки-Фуллера для анализа структуры данных (для магазина №25).
* Проведение валидации временного ряда с использованием разбиения на обучающую и тестовую выборки.
* Расчет временных факторов, таких как скользящие средние, линии Боллинджера и лаги, для магазина №25 с использованием Pandas.
* Построение и сравнение различных моделей прогнозирования (скользящее среднее, линейная регрессия, ARIMA) для продукта №103501, с оценкой их качества с помощью метрик MSE, MAE, MAPE.
* Применение более продвинутых моделей, таких как Prophet, XGBoost и CatBoost, а также учет влияния национальных праздников для улучшения точности прогнозов.


## 3. Основные характеристики данных

Исходные данные включают в себя даты, информацию о магазине и товаре, а также фактические и прогнозные объемы продаж.

* **Объем данных**: 125 497 040 записей, 6 признаков (после обработки).
* **Признаки в данных**:
    * `id` (идентификатор записи)
    * `date` (дата продажи)
    * `store_nbr` (номер магазина)
    * `item_nbr` (номер товара)
    * `unit_sales` (объем продаж) - целевая переменная
    * `onpromotion` (наличие акции на товар)


## 4. Используемые технологии и библиотеки

* Python

* Numpy (для численных операций)
* Scikit-learn (для метрик и моделей)
* Prophet (для прогнозирования временных рядов)
* XGBoost (для бустинговых моделей)
* CatBoost (для бустинговых моделей)
* Matplotlib, Plotly (для визуализации данных)
